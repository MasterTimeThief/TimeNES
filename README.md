# TimeNES
NES Emulator built in Go

This emulator was built using the guide by [100th_Coin](https://www.patreon.com/100th_Coin/posts/making-your-nes-137873901), though I do plan to expand on it to add features and icrease its accuracy.

Things I'll work on implementing:

- APU Support
- NTSC Video Rendering
- Palette Support
- Cartridge Mapper Chips
- AccuracyCoin tests (41 / 141)
- Better CPU cycle accuracy

Currently supports:
- CNROM
- 2 players
- All official opcodes
